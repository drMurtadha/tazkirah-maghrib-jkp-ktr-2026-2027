35 slaid web. Buka `index.html` terus dalam pelayar atau terbitkan melalui GitHub Pages. Semua imej lafaz terbenam dalam HTML. Internet tidak diperlukan untuk pembentangan selepas fail dimuat turun. Pautan sumber memerlukan internet.

## Kawalan

- Anak panah kanan/kiri, Page Down/Up atau Space: tukar slaid.
- Home / End: slaid pertama / terakhir.
- F: skrin penuh, jika disokong pelayar.
- N: nota pembentang.
- G: senarai semua slaid.
- B: gelapkan paparan; tekan B semula atau klik untuk kembali.
- Telefon: leret ke kiri atau kanan. Butang navigasi turut disediakan.
- Pautan terus: `#slaid-9`, sebagai contoh.
- Cetak melalui menu pelayar untuk mencetak semua slaid.

## Terbitkan melalui GitHub Pages

Cadangan nama repositori: `tazkirah-maghrib-jkp-ktr-2026-2027`.

1. Cipta repositori baharu di akaun `drMurtadha`.
2. Muat naik `index.html`, `Ratib_AlAttas.pptx`, `.nojekyll`, `README.md` dan `SEMAKAN_SUMBER.md` ke cabang `main`.
3. Dalam Settings → Pages, pilih Deploy from a branch, `main`, `/(root)`.
4. Buka URL yang dipaparkan oleh GitHub selepas penerbitan selesai.

Alternatif terminal Mac yang mempunyai GitHub CLI: jalankan `bash publish-github.sh` dari folder ini. Skrip memerlukan akaun GitHub yang telah dilog masuk dan akan mencipta repositori awam baharu. Ia berhenti jika nama repositori telah digunakan.

## Kandungan dan rujukan

Sumber utama: Mohd Azman Mohsin et al. (2016). Ratib al-Attas Menurut Perspektif al-Quran dan Hadis. *Sains Humanika*, 8(3–2), 101–107. https://doi.org/10.11113/sh.v8n3-2.970

Rujukan ayat dan hadis diperiksa silang pada Quran.com dan Sunnah.com. Lafaz zikir 8 diperbetulkan berdasarkan Quran NU Online. Perincian ada dalam nota setiap slaid dan `SEMAKAN_SUMBER.md`.

PPTX dan laman web menggunakan kandungan yang sama. Huraian Bahasa Melayu ialah parafrasa. Pembentangan ini menghuraikan artikel dan bukan edisi kritikal kitab ratib atau takhrij lengkap semua riwayat.
